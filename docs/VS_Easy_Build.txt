========================================================================
🚀 PSYCHOBUDDY: EASY BUILD GUIDE (Step-by-Step)
========================================================================

STEP 1: INSTALL THE TOOLS
------------------------------------------------------------------------
1. Download "Visual Studio Community" (it's free) from: visualstudio.microsoft.com
2. When installing, look for the "Workloads" tab.
3. CHECK THE BOX that says: ".NET desktop development".
4. Click "Install" and wait for it to finish.

STEP 2: SETUP THE FOLDER
------------------------------------------------------------------------
1. Create a new folder on your Desktop named "PsychoBuddy".
2. Put the "PsychoBuddy.csproj" file inside that folder.
3. Create a folder inside "PsychoBuddy" called "src".
4. Put all the folders from the /src directory (Brain, Core, Muscles, Senses, UI) 
   and the "Program.cs" file into that "src" folder.

Your folder should look like this:
- PsychoBuddy/
  - PsychoBuddy.csproj
  - src/
    - Program.cs
    - Brain/ (all .cs files)
    - Core/ (all .cs files)
    - Muscles/ (all .cs files)
    - Senses/ (all .cs files)
    - UI/ (all .cs files and MainWindow.xaml)

STEP 3: THE MAGIC BUTTON (BUILDING)
------------------------------------------------------------------------
1. Double-click the "PsychoBuddy.csproj" file. Visual Studio will open.
2. Look at the top menu. Click "Build" -> "Build Solution".
3. If you see "Build: 1 succeeded" at the bottom, your .exe is ready!

STEP 4: LAUNCHING
------------------------------------------------------------------------
1. Go to the folder: PsychoBuddy/bin/Debug/net6.0-windows/
2. Find the file "PsychoBuddy.exe".
3. RIGHT-CLICK "PsychoBuddy.exe" and select "Run as Administrator".
   (THIS IS MANDATORY. If you don't run as admin, it cannot read the game memory).

========================================================================
TROUBLESHOOTING:
- "Access Denied" -> You didn't Run as Administrator.
- "Missing Reference" -> You didn't copy the folders into the /src directory correctly.
- "No clients found" -> Open WoW first, then run the program.
